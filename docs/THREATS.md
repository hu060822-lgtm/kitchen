# 威脅系統（ThreatSystem）

程式：`server/src/kitchen/threats/`。數值都是檔案開頭的常數（`MONSTER`、`GUEST`），沒有任何隨機。

## 0. 能碰什麼、不能碰什麼

恐怖系統透過 `ThreatWorld` 介面（`threats/types.ts`）跟廚房互動，只拿得到：

- 每位玩家的位置、朝向、蹲下、狀態（正常／被關／躲著）
- 門（防火門）與監視器有沒有人在看
- 這一步的噪音事件（位置、半徑、來源）
- 動作：`trap(role)`（關進鐵籠）、`emit(event)`（依感官送出的事件）

它**拿不到**食材、鍋子、盤子、訂單或評分，因此沒有任何途徑改變料理的結果。

## 1. 後門的東西（Monster）

```
dormant ──飢餓值 ≥ 60──▶ lurk（在後門外刮門 6 秒：全隊收到警告＋刮門聲＋燈閃）
lurk ──這 6 秒內鎖上後門──▶ dormant（飢餓值 −15，「後門被撞了兩下……」）
lurk ──6 秒到──▶ 進門，chase 最近的人（用實際走路的距離算；不追餐廳裡、躲著、被關、斷線的人）
chase ──追滿 20 秒──▶ 換追另一個最近的人（只剩一個人就繼續追他）；新的目標私下收到「牠盯上你了」
chase ──目標躲起來／跑進餐廳／被抓／斷線──▶ 換追另一個最近的人；一個都沒有 ──▶ patrol（一有人出現就追）
chase ──1.3 m 內、看得到──▶ windup（0.75 秒預備，聽得到的吼聲＋看得到的撲身）
windup ──目標還在 1.6 m 內──▶ 抓走 ──▶ 接著追下一個人
windup ──目標逃開──▶ chase
進門後 60 秒（不分區域）──▶ 剩 5 秒低吼預警 ──▶ leave（從後門離開；抓過人：飢餓值 −30）
防火門關著、牠在後走廊／側走廊 ──▶ bang（走到門前撞門 2.5 秒，全隊聽到、門在震）──▶ leave（飢餓值 −15）
後門鎖著（20 秒）──▶ dormant 進不來（飢餓值照樣累積，上限 90；門一開就開始刮門）
```

門禁（監視器，兩個按鈕共用 45 秒冷卻）：
- **鎖後門** 20 秒：預防。聽到刮門聲的 6 秒內去鎖就擋得住；牠已經在裡面時不能用（按了會說明）。
- **關防火門** 15 秒：驅趕。牠在防火門外側（後走廊、側走廊）時有效；在廚房、冷藏室、乾貨室時只是擋住一條路。
- 玩家看得到：畫面上方顯示「後門外有東西在刮門！N 秒後進來」、牠還會待幾秒、正在撞門、正在離開，以及兩扇門的剩餘秒數；監視器上有「後門外的動靜」（0–100%）。
- 牠在場時（刮門、追人）背景音樂換成緊張的版本，離開後換回來。

| 參數 | 值 |
| --- | --- |
| 飢餓值 | 在後門外每秒 +1；每個噪音 +半徑 × 1.2；≥ 60 開始刮門 |
| 追誰 | 最近的人（實際走路的距離）；直接知道目標在哪，不需要看見；每 20 秒換一次 |
| 速度（m/s） | 巡邏 2.0、追逐 3.8、離開 2.2（玩家走 2.3、跑 4.4：跑得掉，但要一直跑） |
| 抓人 | 1.3 m 內、看得到就開始預備，0.75 秒後目標仍在 1.6 m 內才抓到 |
| 停留 | 進門後 60 秒，時間到從後門離開 |
| 地盤 | 後場與廚房；不進餐廳 |
| 路網 | `nav.ts`：節點只用來定巡邏點；實際走路用 12.5 cm 細格子上的 A*（和家具保持 0.3 m），路徑拉直；防火門關著時用另一張格子圖 |
| 不卡住 | 起點永遠是牠現在的位置；每秒檢查有沒有前進，沒有就重新找路，第二次先退到旁邊空地 |
| 擺脫 | 刮門時鎖後門；進來之後躲進置物櫃、跑進餐廳、關防火門（牠在走廊時），或撐到 60 秒 |

每晚（連續七晚）與無盡模式會調整倍率：想進來的門檻、對聲音的敏感度、待多久、速度（追人的速度永遠比人跑步慢）、追同一個人多久才換人、離開後多快回來。

噪音半徑（公尺）：切菜 5、鍋鏟碰撞（放東西）3.5、大火 4、吐司跳起 5、丟垃圾 4、跑步 6、回聲 7、湯滾 3。

牠身上是濕的：在廚房、冷藏室、乾貨室裡每 7 秒滴下一灘水（跑過去會滑倒）——恐怖系統只透過 `spill` 在地上留水，不碰料理。

出現時的預警：刮門的 6 秒是危險事件，每個人都收到（文字、刮門聲、燈閃）；進門時聽得見的人聽到後門吱一聲（空間音效）。在場時，聽得見的人一直聽得到牠的呼吸與沉重的腳步（空間音效），看得見的人在牠靠近時看到燈光不穩。

被抓走：被抓的人看到約 3.6 秒的過場（視角被扳向牠、牠撲到臉前、被拽倒在地往上看、黑幕裡的爪痕與拖行聲），然後在冷藏室的鐵籠裡醒來，面向籠門；手上的東西保留，只能轉頭。其他人只看到牠撲上去與拖走的聲音。
出來的方法：隊友在鐵籠前撬開（2.5 秒，離開就中斷），或自己搖開鐵籠——沒有隊友能救（單人、其他人都被抓或斷線）時 7 秒，有隊友時 18 秒。搖鐵籠很吵（開始時與每 3 秒一次、半徑 7 m 的噪音），怪物可能回來。開發者工具「被怪物抓（過場）」可以直接測試。

躲進置物櫃：牠會改追另一個人（沒有別人就在附近巡邏）；牠不會打開櫃子。

## 2. 永遠沒有點餐的客人（Guest）

唯一的規則：**沒有人看著他的時候，他才會動。**

| 參數 | 值 |
| --- | --- |
| 出現 | 營業 45 秒後，在最遠的座位 |
| 「看著」 | 任何玩家在 16 m 內、視線沒被牆擋住、他在畫面中央 ±45°；或有人正在看監視器 |
| 移動 | 沒人看的時間累積 7 秒 → 往前一個位置：座位 → 門口 → 廚房 → 出餐口前；之後沒人看時慢慢跟著最近的人 |
| 實體 | 進到門口與廚房後會擋路（伺服器的碰撞也算他） |
| 請回座 | 任何人站在他面前按 E，2 秒；之後安靜 30 → 22 → 14 → 12 秒 |
| 說話 | 2.2 m 內的人會收到他的話（文字給看得見的人、語音播報給看不見的人） |

耳背砧板聽不到椅子被拖動與腳步聲（沒有替代文字），只能靠看。他不攻擊、不碰任何東西。

## 3. 為什麼這樣設計

- **可以學習**：每個條件都可觀察（噪音、燈光、視線、蹲下、門），玩家能歸納出規則並改變做菜的方式（少用大火、切菜時派人看著後場、出餐口前留人）。
- **打斷節奏，不打破規則**：最壞的情況是「少一個人、爐子沒人顧」，而不是「分數被扣」或「食物憑空壞掉」。
- **不是倒數計時**：沒有任何固定時間的出現或死亡；出現時機取決於你們的噪音，客人取決於你們的分工。

## 4. 測試
